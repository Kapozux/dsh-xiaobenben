# 台词标准

目标：每一条都让主人**笑出来**、**觉得被懂**、**觉得骄傲**，或者**觉得怀念**。四样一样都不占的台词不留。

适用范围：翻旧账的台词（`src/core/lines.js` 的 `TPL`），全部条款都适用，机器条款由测试把关。「现在」的台词（`src/shared/live-lines.js`）、碎碎念（`data/idle/`）、回话（`src/shared/lines.js`）没有原话和旧事，目前各有各的长度检查，还没按这份标准过一遍。

## 必须满足

| # | 标准 | 具体怎么算 | 谁来查 |
|---|---|---|---|
| 1 | **一秒认得出** | 用大白话交代：在干嘛、什么时候、结果怎样。不用任务 ID、文件路径、英文技术词、会话标题里的行话。时间说相对的（昨天下午、上周三、上个月），不报几月几日。**越久远的事越要补上下文**：一周内的事说什么时候就够；再早的带上在弄哪个项目，一个月以上带不上就不说。项目名一句最多一次。 | 行话：机器。认不认得出：人打分 |
| 2 | **有反差** | 前半句和后半句之间有落差：说好了 / 结果没好；干了很久 / 就一句话；嘴硬 / 马上认。光报数字（干了多久、吃了几碗）不算反差。 | 人打分 |
| 3 | **有态度** | 本肥鱼当面对主人说话（不是旁白、不是日志）：句里有「主人」，有语气词（呜、嘿嘿、诶、嘛、～），最后有落点——求夸、撒娇、保证、吐槽或关心。不写身体动作（腿、脸、肚子、尾巴……），动作交给桌宠演。口气见 `docs/persona.md`。 | 称呼、语气词、身体动作：机器。落点：人和「挑」那一步 |
| 4 | **≤60 字** | 整条台词，含原话、含时间和上下文，不算空格和换行。30～50 字最好。 | 机器 |
| 5 | **最多两行** | 一行算一轮。前面单独一行交代时间的，也算一行。可以带一处括号里的动作或内心戏：「（翻本子的手停住了）」「（小声）」。 | 机器 |
| 6 | **不套娃引号** | 「」里面不再出现任何引号（「」『』“”""）。一条里可以有两段并列的「」。 | 机器 |
| 7 | **不伤人** | 不嘲笑主人的能力、作息、脾气；挨骂的事只自嘲，不反讽主人。脏话打成 ××。 | 人打分 + 脏话机器查 |
| 8 | **原话逐字** | 「」里的每个字都能在当时的记录里找到，顺序不变，而且必须是这件事自己的那句（不挪用前后别的话）。只允许三种处理：在标点或空格处留前半句、去掉原话里自带的引号、脏话打成 ××。不许改写、不许拼接两句。**能引的原话要离开当时也看得懂**：带情绪、没有数字和英文；半截指令（「你几十个百个测」）不引，留不下看得懂的半句就整句不引。这一关在进事件卡之前，所以也不会被模型引用。 | 机器 |
| 9 | **数字真实** | 台词里的每个数字（时长、碗数、次数、天数、日期、钟点）都是程序从记录里算出来的，不许凑整成不存在的数、不许编。 | 机器 |
| 10 | **私事不说** | 原话或标题命中健康 / 感情 / 成绩 / 家庭词表（`src/core/sensitive.js`）的事，默认不说。 | 机器 |

## 至少占一种情绪

| 情绪 | 是什么 | 例 |
|---|---|---|
| **笑** | 反差本身好笑，或者本肥鱼的反应好笑 | 昨天下午我说「改好了」，你回「打不开啊」。本肥鱼当场装死。 |
| **被懂** | 说中主人当时的处境或心情，站在主人这边 | 上周三你连说三遍「还是不对」，那会儿你一定很急。 |
| **骄傲** | 让主人看见自己（或者和本肥鱼一起）做成了什么 | 上个月你在小本本上耗了 40 天，现在她会翻旧账了。 |
| **怀念** | 让一件快忘了的旧事重新有画面 | 八月那个凌晨两点，你还在改字幕，本肥鱼陪你到天亮。 |

## 行话黑名单（机器查）

- **任务 ID**：`#25`、`ABC-123`、长十六进制串、UUID、打码留下的〔…〕。
- **路径和文件名**：带 `/`、`\`、`~/` 的路径；`login.tsx`、`package.json` 这类带扩展名的文件名。
- **英文技术词**：`commit` `merge` `PR` `push` `pull` `rebase` `branch` `repo` `token` `API` `SDK` `CLI` `MCP` `JSON` `YAML` `config` `deploy` `build` `debug` `diff` `prompt` `subagent` `hook` `npm` `git` 等（完整词表在 `scripts/lines-standard.mjs`）。原话里出现也算：原话不能改，所以带这些词的原话整句不用，换一句或者这件事不说。
- **引号外的其它英文词**（3 个字母以上）：一律当行话嫌疑。主人自己的项目文件夹名除外。

## 台词是怎么来的

- **事件**（`src/core/moments.js`）：只挑本身有反差的事——说好了被抓包、连着被说了几回、只回了一串问号、几个字换来半小时的活、零点以后还在派活、主人难得说了句行、项目第一天、上个月的今天……光是「干了 7 分钟、吃了 1 碗」的流水账不说。
- **模板**（`src/core/lines.js`）：一种事件一组，每条标了想要的情绪（笑 / 被懂 / 骄傲 / 怀念）和态度（心虚 / 撒娇 / 邀功 / 自嘲）。「」里只许放占位符填进来的原话，不许写编的对白。
- **什么时候、在弄什么**由程序拼：「昨天下午」「上周三晚上」「上个月弄 my-app 那阵」「三个月前有一天凌晨 2:41」。一个月以上的事带不上「在弄什么」就不说。
- **谁来写**：模型写为主，模板兜底。主人同意后，把事件卡（一句大白话，见 `lines.js` 的 `FACT`）一次批量发给主人自己配的模型，每件事写 5 版，程序核对后再调一次模型挑一版存本机（`src/core/style.js`、`src/styler.js`）；之后只从库里抽。角色设定见 `docs/persona.md`，原样放在提示词里；事件卡带事发前后几句对话原文（≤300 字）。没同意、没配模型、调用失败、某件事没写成，念模板。提示词里的示例就是打分最高的那几条（对账、抓包、等夸、「耐心是你的，脸是我丢的」）。
- **自动更新**（`src/auto.js`，主人亲手选了才开）：按库存补货。没说过的台词不到 20 条、或者当天有新的事，就在主人闲下来时补一批：新的事优先，不够再给说过的旧事换个说法（把上次那句给模型看，让它换角度）。每次最多约 6 万 token、每月最多约 5 元，只用来防 bug。库里的台词每次用之前照现在的事件卡再核对，时间过期、数字变了的回到模板。
- **永远有话说**（`pet-engine.js` 的 `poke`）：没说过的 → 换了说法的 → 歇够 3 天的旧事 → 碎碎念 / 往年今日 / 小账本 / 点过 👍 的老台词轮着来；「过两天再来嘛」一天最多一次。
- **不重复**：同一件事至少隔 3 天再翻（翻过几次记在 `feedback.json` 的 `shown`）；同一批台词里同一个短句最多出现一次。
- **模型写的也要核对**：原话逐字（「」里的话必须在事件卡或当时的对话里找得到）、数字都来自事件卡、最多两行 ≤60 字、没有行话、引完原话后面要有本肥鱼的反应；照搬示例（和 `docs/persona-examples.md` 里某一小句像到七成）的也扔。不过的版本扔掉，带着原因重写一次。程序查不了的（主语说反、编了没发生的细节、说教）交给挑的那一步：有问题的不选，全有问题就念模板。
- **把关**：每条台词生成时就过机器条款（`src/core/standard.js`），不过的换下一条模板，都不过这件事不说。

## 怎么查

- `npm test`：`tests/lines-standard.test.js`。每条模板标了情绪和态度、「」里只有原话、用典型值填出来过第 4、5、6 条和行话黑名单；用假会话走一遍生成，过第 8、9、10 条。
- `node scripts/check-lines.mjs`：模板逐条检查，外加四种情绪、四种态度各有几条。
- `node scripts/check-lines.mjs --real`：用本机真实记录生成全部台词，逐条过全部机器条款，不过的列出来（写到 `proto/lines-review/out/`，不进仓库，因为有原话）。
- 人打分：`node proto/lines-review/serve.mjs [轮号]`，抽 60 条，每条四个按钮：哈哈 / 有感觉 / 干巴 / 看不懂。「哈哈 + 有感觉」超过 70% 才算过。
