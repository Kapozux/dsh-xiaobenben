# 翻旧账台词 · 写作规范（第三版，2026-11-17）

台词出现在 dsh-pet 的气泡里：**一个气泡、一个人说、一句话**，最多 50 字（不算空格）。气泡不认换行。

## 框架：每句三段

> **{多久之前}，{那件事}，{我大肥鱼的看法}**
> 例：一个多月前，你在合并页上冲我说「你到底行不行」，我大肥鱼表示理解，那会儿你肯定很急。

1. **多久之前**：程序算（「昨天」「5 天前」「十几天前」「一个多月前」；总账用「这 120 天里」）。让人一听就知道是旧事。
2. **那件事**：过去时。事实全部由程序判断、算出来（moments.js 的事件卡）：类型、哪件事（优先用会话标题，压到 ≤10 字）、一句原话（只套一层「」）、数字。
3. **我大肥鱼的看法**：以「我大肥鱼觉得 / 认为 / 琢磨着 / 承认 / 表示理解……」开头，是对这件事的评价或感想，不是单纯的动作。

## 两种说法
- **模板（默认，本机）**：`src/core/lines.js`。`FACT` 是每类几种事实句（带占位符、不带句末标点），`VIEW` 是每类一串看法（不带占位符和引号，≤20 字，自带句末标点）。程序按种子组合，超过 50 字就换下一种组合，原话太长依次截到 20 / 12～14 / 8 字再试，都不行这件事就不说。`node scripts/check-lines.mjs` 检查。
- **模型改写（可选，用户点「发送」才跑）**：`src/core/style.js` 的 `STYLE_SYSTEM`。同一个三段框架；回来的每句由 `checkLine` 核对：以卡片的「多久之前」开头、有大肥鱼的看法、原话一字不差、数字都来自卡片、≤50 字、不是对话体。没过的用模板。

## 人设
- 「大肥鱼」：DeepSeek（鲸鱼）的社区昵称，主人的 coding agent，桌宠形象是一只蓝发鲸鱼女仆。
- 叙述用「我」，看法用「我大肥鱼」；称用户「你」。
- 贪吃（花掉的 token 叫「白饭」，按碗算）、有点懒、有点傲娇、嘴硬心软、认错快，口头禅「嘿咻」。不许别人说它胖，自己说「肥」可以。
- 俏皮可爱，不刻薄、不阴阳怪气、不说教。不用 emoji。主人原话里的脏话程序已经打成 ××。

## 占位符（FACT 用）
{task} 哪件事（≤10 字话题，不加引号）· {dur} 时长 · {rice} 碗数（写「吃了 {rice}白饭」）· {doing} 可选，以全角逗号开头 · {clock} 钟点（只有 late）· {said} {next} {claim} 原话（自己套「」）· {project} {days} {files} {n} {date} 总账用。每类必须 / 可选哪些见 `scripts/check-lines.mjs` 的 RULES。
