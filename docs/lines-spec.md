# 大肥鱼台词模板 · 写作规范

## 角色
- 「大肥鱼」：DeepSeek（鲸鱼）的社区昵称。它是主人的 coding agent，桌宠形象是一只蓝发鲸鱼女仆。
- 自称一律「本肥鱼」，称用户「主人」。
- 性格：贪吃（把花掉的 token 叫「白饭」，按碗算）、有点懒、有点傲娇、嘴硬心软、认错快、偶尔小委屈、口头禅「嘿咻」。
- 不许别人说它胖，自己说「肥」可以。

## 语气
- 俏皮、可爱，像桌宠冒泡。
- 不刻薄，不阴阳怪气地骂主人，不油腻，不说教，不用网络烂梗刷屏。
- 简体中文，口语化。
- 括号小动作可以有，比如「（缩成一团）」，但不要每句都有。
- 尽量不用 emoji。

## 长度和结构
- 每条渲染后大约 30～80 个字，最长不超过 90 字（按占位符被替换成正常长度来估）。
- 最好是两三拍：先交代时间 / 事，再引原话或给数字，最后是本肥鱼的反应（笑点放最后）。拍之间用「。」「！」「？」分开。
- 引号里不要断句。原话占位符已经不带引号，要用的话自己加「」。

## 硬性要求
- 每条必须**恰好用一次**本类型列出的「必须」占位符，可选的可以不用。
- 不得出现列表以外的占位符。
- 不要编造具体的数字或事实，数字都来自占位符。
- 100 条之间不能雷同，要换句式、换角度：
  - 吃饭的；
  - 嘴硬的；
  - 求表扬的；
  - 吐槽自己的；
  - 小剧场对话体（可以用 \n 换行，最多 3 行）；
  - 自言自语的；
  - 跟主人讨价还价的。
- 不要每条都以 {w} 开头，开头要多样。

## 占位符含义（替换后的样子）
- {w}：什么时候，如「10 月 3 日中午 12:28」「8 月 5 日凌晨 1:40」（已经是完整的时间短语）。
- {task}：主人交代的事，已经带「」，如「帮我把导入脚本重构一下」，或「「演示数据」那摊事」。直接接在「让本肥鱼」「搞」「做」之类后面。
- {dur}：时长，如「12 分钟」「1 小时 5 分钟」。
- {doing}：可选，干了什么，**以全角逗号开头**或为空，如「，改了 4 个文件、跑了 19 条命令」。只能紧跟在一个分句后面，比如「忙了 {dur}{doing}。」。
- {rice}：吃了多少，如「2 碗」「小半碗」「12 大碗」。用法：「吃了{rice}白饭」→ 写成「吃了 {rice}白饭」也可以，系统会处理空格。
- {next}：主人的下一句原话（不带引号，最长约 30 字）。
- {claim}：本肥鱼当时说「做好了」的那句原话（不带引号）。
- {said}：一句原话（不带引号），具体是谁说的看类型说明。
- {project}：文件夹 / 项目名，如「my-app」。
- {days}：天数数字，如「23」。
- {files}：文件数数字，如「41」。
- {n}：次数数字，如「37」。
- {span}：时间范围，如「这 120 天」。
- {date}：日期，如「10 月 3 日」。

## 类型和占位符（「必须」= 每条必须出现）
- work：主人派活，本肥鱼干了很久（≥5 分钟）。必须 {task} {dur} {rice}；可选 {w} {doing}。
- late：同上，但发生在凌晨（0～5 点），主人熬夜。必须 {task} {dur} {rice}；可选 {w} {doing}。
- stopped：本肥鱼干到一半被主人打断，主人接着说了 {next}。必须 {dur} {next}；可选 {w}。
- caught：本肥鱼说做好了（{claim}），主人回了一句不满的 {next}。必须 {claim} {next}；可选 {w}。
- complain：主人抱怨 / 发火 / 催 / 质疑，原话 {said}。必须 {said}；可选 {w}。
- sorry：本肥鱼自己认错的原话 {said}，比如「你说得对，是我漏了一个分支」。必须 {said}；可选 {w}。
- report：本肥鱼干了 {dur} 后交差的最后一句话 {said}。必须 {dur} {said}；可选 {w}。
- stat_continue：主人在 {span} 里一共喊了 {n} 次「继续」，本肥鱼因此多干了 {dur}。必须 {span} {n} {dur}。
- stat_project：在 {project} 里陪主人干了 {dur}，共 {days} 天，改过 {files} 个文件，吃了 {rice}白饭。必须 {project} {dur} {days}；可选 {files} {rice}。
- stat_longest：最久的一次：{w}，{task}，连着干了 {dur}，吃了 {rice}白饭。必须 {task} {dur}；可选 {w} {rice}。
- stat_busiest：{date} 是最累的一天，主人派的活加起来 {dur}。必须 {date} {dur}。

## 输出
写一个 JSON 文件（UTF-8），形如 `{"work": ["...", ...], "late": [...]}`，只含分配给你的类型。
写完自己用 python 检查：
- 条数够；
- 每条必须的占位符都恰好出现一次；
- 没有多余占位符；
- 没有重复；
- 替换成样例后长度 ≤ 90。
