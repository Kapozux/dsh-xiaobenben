# 大肥鱼台词模板 · 写作规范（第二版，2026-11-17）

台词出现在 dsh-pet 的气泡里：**一个气泡、一个人说、一句话**。气泡不认换行（实测 `white-space: normal`，`\n` 会变成空格）。

## 角色
- 「大肥鱼」：DeepSeek（鲸鱼）的社区昵称，主人的 coding agent，桌宠形象是一只蓝发鲸鱼女仆。
- 自称「本鱼」或「本肥鱼」（「本鱼」更短，优先），称用户「主人」。也可以不自称，直接说。
- 性格：贪吃（花掉的 token 叫「白饭」，按碗算）、有点懒、有点傲娇、嘴硬心软、认错快、偶尔小委屈、口头禅「嘿咻」。
- 不许别人说它胖，自己说「肥」可以。

## 语气
- 俏皮、可爱，像桌宠冒泡。不刻薄、不阴阳怪气、不油腻、不说教、不刷网络烂梗。
- 简体中文，口语。括号小动作偶尔用，比如「（缩成一团）」。不用 emoji。

## 硬性规则（`node scripts/check-lines.mjs` 会逐条查，过不了不收）
1. **只有本鱼一个人在说**：不写对话体，不出现「本肥鱼：」「主人：」「本鱼：」这类说话人标签，不出现换行。
2. **原话最多一层「」**：原话占位符（{said} {next} {claim}）不带引号，要用就自己套一层「」。{task} 不是原话，**不要**给它加引号。caught 是唯一能有两处引号的类型（本鱼自己说的 {claim} + 主人的 {next}）。
3. **≤ 40 字**：占位符换成「典型值」（见下表）后，不算空格，最多 40 字。越短越好，25～35 字最舒服。
4. 每条必须用到本类型「必须」的占位符（「其一」= 列出的里至少用一个），每个占位符最多出现一次，不能有列表以外的占位符。
5. 不编造数字和事实，数字都来自占位符。
6. 同一类里不能重复，开头要多样（不要都以 {w} 开头），角度轮换：吃饭的、嘴硬的、求表扬的、吐槽自己的、自言自语的、跟主人讨价还价的、撒娇的。
7. 句子是**一拍或两拍**：事实 + 态度。不要三拍。

## 占位符（典型值，检查时就用它算长度）
| 占位符 | 典型值 | 说明 |
|---|---|---|
| {w} | 11 月 4 日凌晨 | 日期 + 时段，已经是完整短语，不带钟点 |
| {clock} | 1:02 | 钟点，只有 late 能用 |
| {task} | 导入脚本重构 | 主人派的活，已压成 ≤10 字的话题，**不带引号**，可以写「{task}那摊事」「{task}那活」 |
| {dur} | 12 分钟 | 也可能是「1 小时 5 分钟」 |
| {doing} | ，改了 4 个文件 | 可选，**以全角逗号开头**或为空，只能紧跟在一个分句后面：「忙了 {dur}{doing}。」 |
| {rice} | 3 碗 | 也可能是「小半碗」「12 大碗」。写「吃了 {rice}白饭」 |
| {said} | 你说得对，是我漏了 | 原话，≤14 字，不带引号 |
| {next} | 还是不对啊 | 主人的下一句原话，≤12 字（caught）/ ≤14 字（stopped），不带引号 |
| {claim} | 改好了，测试全过了 | 本鱼当时说「好了」的原话，≤12 字，不带引号 |
| {project} | my-app | 文件夹名 |
| {days} {files} {n} | 23 / 41 / 37 | 纯数字 |
| {span} | 这 120 天 | |
| {date} | 10 月 3 日 | |

## 类型
- work：主人派活，本鱼干了 ≥5 分钟。必须 {task}，其一 {dur} {rice}；可选 {w} {doing}。
- late：同上，但在凌晨（0～5 点），主人熬夜。必须 {task}，其一 {dur} {rice}；可选 {w} {clock} {doing}。
- stopped：本鱼干到一半被主人打断，主人接着说了 {next}。必须 {next}；可选 {dur} {w}。
- caught：本鱼说做好了（{claim}），主人回了一句不满的 {next}。必须 {claim} {next}；可选 {w}。
- complain：主人抱怨 / 发火 / 催 / 质疑，原话 {said}。必须 {said}；可选 {w}。
- sorry：本鱼自己认错的原话 {said}。必须 {said}；可选 {w}。
- report：本鱼干了很久后交差的最后一句 {said}。必须 {said}；可选 {dur} {w}。
- stat_continue：主人在 {span} 里喊了 {n} 次「继续」，本鱼多干了 {dur}。必须 {n}；可选 {span} {dur}。
- stat_project：在 {project} 里陪主人干了 {dur}，{days} 天，改过 {files} 个文件，吃了 {rice}白饭。必须 {project} {dur}；可选 {days} {files} {rice}。
- stat_longest：最久的一次：{w}，{task}，连着干了 {dur}。必须 {task} {dur}；可选 {w} {rice}。
- stat_busiest：{date} 最累，活加起来 {dur}。必须 {date} {dur}。

## 运行时
填出来超过 40 字（真实的原话、任务名可能比典型值长），程序会按顺序换下一条模板；一条都塞不下就不说这件事。所以**短模板越多，能说的事越多**。

## 例子
- ✅ `主人，天都要亮了。{task}那摊事，本鱼 {dur}搞定，吃了 {rice}白饭。`
- ✅ `「{said}」……本鱼认错认得可快了，不许笑。`
- ❌ `本肥鱼：「好了。」主人：「「{task}」那摊事呢？」`（对话体、说话人标签、套娃引号）
