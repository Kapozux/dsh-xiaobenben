# 气泡字体

`xbb-rounded.woff2` 是 **Resource Han Rounded CN Medium（思源柔黑）** v0.990 的子集：
只留了 GB2312 的 7,000 多个常用汉字、ASCII 和常用标点（从 38MB 压到约 1.2MB），转成 woff2。子集里没有的字由系统字体补上。
